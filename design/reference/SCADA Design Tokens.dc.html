Design System · Fundaciones · v1.0

Tokens fundacionales SCADA

Sistema técnico para monitoreo industrial 24/7. Dos temas completos sobre el mismo set de tokens semánticos: Dark (modo principal, sala de control con baja luz ambiente) y Light (oficina, reportes impresos, exteriores con alta luminancia). Cada estado se recalcula por tema para conservar jerarquía de urgencia y contraste mínimo AA sobre su propio fondo.

React + Tailwind CSS variables · dark: variant Base 4px Sin componentes — solo fundaciones
01

En Dark las superficies suben por luminancia (nunca por sombra); en Light bajan por sombra y el card es blanco puro para maximizar contraste con el fondo gris frío.

Cada uno con cuatro tokens: -solid (íconos, indicadores, barras), -bg (fondo suave de badge/alert/fila), -border (contorno de ese contenedor) y -text (texto sobre el fondo suave). 03

Tipografía

Sí conviene una familia monoespaciada aparte: los valores de proceso cambian varias veces por segundo y con anchos proporcionales los dígitos «bailan» horizontalmente, lo que impide leer una tendencia de un vistazo. Regla del sistema: todo número que representa una medición, un tag, un timestamp o un código va en mono; todo lo demás va en la sans.

font-family-ui
IBM Plex Sans
Diseñada para interfaz técnica: alta diferenciación de caracteres (1 / l / I, 0 / O), formas abiertas y buen rendimiento a 12–14px. Pesos en uso: 400 / 500 / 600 / 700.

font-family-mono
IBM Plex Mono
Ancho fijo para valores de proceso, tags de instrumento, timestamps y logs. Comparte esqueleto con la sans, así que conviven sin ruido. Usar tabular-nums siempre.

05

Radios, bordes y elevación

Radios cortos: el lenguaje es instrumental, no consumer. La elevación es el único bloque que no se comparte entre temas: en Dark la jerarquía se construye con luminancia y halo (una sombra negra sobre fondo negro no existe); en Light con offset y desenfoque tradicionales.
